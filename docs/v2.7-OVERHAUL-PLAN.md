# v2.7 — 架构收敛、人机工效与文档对齐改造清单

本文档定义 v2.7 改造的目标、文档权威分层与四阶段实施规格。改造遵循“整理项目设计文档 → 代码改造 → 优化人机工效 → 重写各处说明文档”的顺序推进。

## 1. 文档权威分层

仓库中的设计文档分为三层，后续说明文档统一引用第一层与第二层文档：

| 分层 | 文件路径 | 定位与职责 |
|---|---|---|
| **现行核心契约** | `AGENTS.md`、`docs/v2-PLAN.md`、`docs/v2-CONTRACT.md`、`docs/STATUS.md` | 定义 v2 产品边界、角色与会话语义、驱动与放置矩阵、二进制与 crate 划分 |
| **现行子系统与增量规格** | `docs/v2.1-HOSTING-RUNTIME-GAPS.md`、`docs/v2.3-CHAT-PROTOCOL.md`、`docs/v2.4-REPLY-THREADS.md`、`docs/v2.5-CANCEL-NOT-ENFORCING.md`、`docs/v2.6-TASK-SETTLED-SWALLOWS-THE-LAST-HOP.md`、`docs/v2.6-VIEW-KEEPS-A-STATE-THE-STREAM-GOT-WRONG.md`、`docs/v2.7-OVERHAUL-PLAN.md`、`crates/onlyne-adapter/PROTOCOL.md`、`crates/onlyne-adapter/HOSTING-RUNTIME.md` | 定义 IM 网关聊天寻址、回复线程、控制结算、视图状态对齐及外部驻留运行时协议 |
| **v1 历史归档** | `docs/v1-PLAN.md`、`docs/v1-PLAN.en.md`、`docs/v1-CONTRACT.md`、`docs/v1-ARCHITECTURE.md`、`docs/v1-DEPS.md`、`docs/live-evidence-1.4.0.md` | 仅记录 v1.x 已归档形态，任何新用户入门文档不再将其列为当前参考 |

## 2. 四阶段改造清单

1. **建立文档权威索引（本文件 `docs/v2.7-OVERHAUL-PLAN.md`）**：明确现行契约与 v1 历史归档的边界，列出全部代码与工效改造的精确到行规格。
