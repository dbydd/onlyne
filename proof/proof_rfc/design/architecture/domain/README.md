# 域成员关系

本模块描述本节点成员关系的提交边界与发现观察。网络认证由节点边界承担。

## 依据

RFC 0011 规定域是无 owner 的节点组。一个节点同时只属于一个域，每个节点只提交自己的成员关系。候选目录提供待核对的身份，候选节点自己的声明决定本次发现的观察结果。

## 为什么

节点组声明与 thread 授权由不同主体确认。域发现取得分散的观察，候选目录无法确认他人的关系。

## 语义

``Domain`Create``、``Domain`Join`` 和 ``Domain`Leave`` 在同一节点的存储事务内串行提交。切换由调用方先退出，再加入；两次提交之间允许崩溃并保持已退出。

``Domain`MembershipRevision`` 的自然数仅表达同一关系的版本围栏，不跨域或跨节点比较。创建的新标识由调用边界分配。

同键重投由事务中的幂等结果直接回答，跳过 ``Domain`Join`` 与 ``Domain`Leave``。历史结果只说明原操作提交过，当前关系通过 ``Domain`Describe`` 读取。附录的效果重合搜索覆盖退出后的迟到重投。

``Domain`Discover`` 的候选可以遗漏节点。查询受超时和取消限制，失败不推断退出。节点分组不改变 thread 的成员授权、资源 endpoint 或 ingress 委托。
