# 接纳

本模块负责接纳与身份去重的原子关系。权限判断由调用方提供。

## 依据

RFC 0003 的发送规则要求先查原结局，再判断当前成员权限。重投窗口规则要求清除明细后保留身份摘要。RFC 0002 要求清除历史后序号继续递增。

## 为什么

``Admission`Log`` 将接纳证据与条目放在一个原子边界。调用方缓存仅表示观察值。

## 语义

``Admission`Expire`` 的调用方必须确认结果保留窗口已经结束。模型限定同一节点身份和一个 thread，节点重启保留整个状态。新请求的期限检查发生在调用 ``Admission`Accept`` 前，已知身份的重投必须先查询原证据。
